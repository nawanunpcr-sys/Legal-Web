## 1. API ใช้ Skill ชุดใหม่จริงหรือไม่ — ใช้ครบทุกตัว

ไล่กราฟ `import` ทั้งโฟลเดอร์ `api/` แล้วไม่มีโมดูลใหม่ตัวไหนถูกทิ้งลอย

```
api/law-analyze.js   → effective-date · guard · osh-law-relate · repeal-match · verify-numbers
api/law-relate.js    → guard · osh-law-relate · verify-numbers
  └ osh-law-relate.js  → anchor-answer · gazette-index · law-source · ref-classify
      └ anchor-answer.js → gazette-index · law-source · open-web-lead · ref-classify · verify-numbers
```

เส้นเรียกที่ยืนยันแล้วว่าเดินถึงจริง:

| เส้น | ผล |
|---|---|
| `POST /api/law-analyze` → `matchRepeals()` | ✓ |
| `POST /api/law-analyze` → `relateAndMerge()` | ✓ |
| `POST /api/law-relate` → `relateAndMerge()` | ✓ |
| `relateAndMerge` → `recheckPending()` · `answerAnchoredQuestion()` · `rememberGazetteDoc()` | ✓ |
| `answerAnchoredQuestion` → `findChildAnnouncements()` (รอบ 0 ดัชนี) | ✓ |
| `answerAnchoredQuestion` → `findLawIdentity()` (รอบกู้) | ✓ |
| `answerAnchoredQuestion` → `resolveGazetteLink()` · `rememberGazetteDoc()` · `sourceTier()` | ✓ |
| `WEB_SEARCH_TOOL` ไม่มี `allowed_domains` แล้ว | ✓ |

**ทั้งสอง endpoint ใช้ทางเดียวกัน** — `law-relate` เป็นคำขอที่ 2 ของโฟลว์ P16 จึงได้ทุกอย่าง
ที่ `law-analyze` ได้ ยกเว้น `matchRepeals()` ซึ่งเป็นงานของฉบับหลักโดยเฉพาะ

## 3. ความถูกต้องของกลไก — เคสที่จับได้ก่อนขึ้น production

ทุกข้อในตารางนี้เป็นบั๊กจริงที่เจอจากการยิงทดสอบ ไม่ใช่ความกังวลเชิงทฤษฎี

| กลไก | เคสที่พัง | แก้ด้วย |
|---|---|---|
| จับคู่บทยกเลิกกับทะเบียน | ฉบับ **2545** จับคู่ไปโดน `LA-005` (**2560**) ที่ยัง active ด้วย `sim` 0.75 พอดี → ขึ้นปุ่มชวนกดยกเลิกฉบับปัจจุบัน | `yearsConflict()` ตัดสิทธิ์ก่อนเกณฑ์ `sim` |
| หาลิงก์ราชกิจจาฯ | เข็ม `"ฉบับที่ 39"` ตรงกับ **"ฉบับที่ 399 ว่าด้วยการยกเว้นรัษฎากร"** | เทียบเลข `ฉบับที่ N` แบบเป๊ะ |
| หาลิงก์ราชกิจจาฯ | ค้น พ.ร.บ.ควบคุมอาคาร 2522 ได้ **คำวินิจฉัยศาลรัฐธรรมนูญ 25/2568** ที่ชื่อเรื่องเอ่ยถึงกฎหมายฉบับนั้น (ด่านปีไม่จับ เพราะปี 2522 อยู่ในชื่อเรื่องด้วย) | ชื่อฉบับต้องอยู่ **ต้นชื่อเรื่อง** ไม่เกิน 12 ตัวอักษร |
| ตาข่ายรอง `discovered` | คลื่น 12 จุดขึ้น **"เจอ 12/12"** แต่ 8 จุดได้ประกาศเรื่องเสียง/แมลงเหมือนกันหมด ทั้งที่ถามคนละเรื่อง | ใช้ได้เฉพาะเข็มชั้นแรก (แกนเต็ม) |
| เปิดชั้น `.go.th` | `krisdika.go.th` · `dlpw.go.th` กลับเข้ามาผ่านด่านโดเมนได้อีก ทั้งที่ยัง `http=000` | ย้ายไปกันที่ `DEAD_SOURCES` |
| ตัวตรวจดัชนีเอง | ตรวจเข้มไปได้ "ไม่ตรง 5 จาก 17" ซึ่ง **ผิด 4 ใน 5** (ฟอนต์ทำวรรณยุกต์หาย) · ตรวจหลวมไปก็ปล่อยแถวที่ผิดจริงผ่าน | แยกสองด่าน: ชื่อเรื่อง (ทนฟอนต์) + เลขฉบับ (ตรวจก่อน) |

> **บทเรียนที่ใช้ซ้ำได้:** ตัวเลข recall ที่สูงขึ้นในระบบแบบนี้ควรเป็นเหตุให้สงสัย ไม่ใช่เหตุให้พอใจ
> "เจอ 12/12" คือสัญญาณว่าเกณฑ์หลวมเกินไป · ตอนนี้ **6/12 และถูกต้องทุกตัว** ซึ่งดีกว่า

## 4. ผลกับกฎกระทรวงควบคุมสถานประกอบกิจการฯ 2560

เอกสารทดสอบ: `https://ratchakitcha.soc.go.th/documents/2115058.pdf`

| รอบ | เวลา (ทำด้วยมือ ไม่เรียก API) | หมายเหตุ |
|---|---|---|
| 1 · ก่อนมีดัชนี | 10:35 | 20+ คำขอ AI |
| 2 · มีดัชนี | 02:38 | ดัชนีช่วย 6/12 · 0 คำขอ |
| 3 · ปลดล็อกการค้น | **01:53** | ดัชนี 6/12 + ค้นเว็บปิดเพิ่ม 3 จุด |

**จุดที่ปิดได้เพิ่มในรอบ 3** — ข้อ 6 วรรคสอง และ ข้อ 22 วรรคสอง ที่ตอบว่า "ยังไม่ยืนยัน" มา 3 รอบ
มีประกาศออกแล้วจริงตั้งแต่ปี 2564:

> **ประกาศกระทรวงสาธารณสุข เรื่อง มาตรการควบคุมและป้องกันเหตุรำคาญฯ ของสถานประกอบกิจการ
> การเพาะพันธุ์ เลี้ยง และการอนุบาลสุกร พ.ศ. 2564**
> *"อาศัยอำนาจตามความในข้อ ๖ วรรคสอง และข้อ ๒๒ วรรคสอง ของกฎกระทรวงควบคุม
> สถานประกอบกิจการที่เป็นอันตรายต่อสุขภาพ พ.ศ. ๒๕๖๐"*
>
> ระยะห่างจากศาสนสถาน/โรงพยาบาล/สถานศึกษา: สุกร 11–20 ตัว ≥ **50 เมตร** · 21–50 ตัว ≥ **100 เมตร**

⚠ **ใช้เฉพาะกิจการเลี้ยงสุกร** ไม่ใช่ระยะห่างทั่วไป — ต้องเขียนใน `applicability` ให้ชัด
ไม่งั้น จป. จะเอา 50 เมตรไปใช้ผิดกิจการ

เส้นทางที่ทำให้เจอ คือรอบกู้ทำงานตรงตามที่ออกแบบ:
`ดัชนีไม่เจอ → ค้นเว็บกว้าง → ข่าว (ชั้น none ตอบไม่ได้) ชี้ว่ามีประกาศ → กลับไปค้น laws.anamai → ดึง PDF จริง → อ่านบทอาศัยอำนาจยืนยัน`
**ก่อนปลดล็อก `allowed_domains` ขั้นที่ 2 เกิดขึ้นไม่ได้เลย**

### จุดที่ยังตอบไม่ได้ (2 จุด)

- **ข้อ 3 วรรคหนึ่ง** — ออกประกาศแล้วเฉพาะ "เสียง" (พ.ศ. 2561) · อากาศ · น้ำ · แสง · ความร้อน
  · ความสั่นสะเทือน ยังไม่พบ
- **ข้อ 21 วรรคสอง** — หลักเกณฑ์ตรวจสุขภาพเพิ่มเติม ยังไม่พบ

ทั้งสองน่าจะยังไม่ออกจริง แต่ตามหลักของระบบเอง **ค้นไม่เจอ ≠ ยืนยันว่าไม่มี**
จึงยังขึ้นเป็น "ต้องตรวจสอบเพิ่มเติม" ไม่ใช่ "ไม่มี"

## 5. สิ่งที่ยังพิสูจน์ไม่ได้ — ต้องรันบนเว็บจริง

การตรวจทั้งหมดข้างบนทำโดย**ไม่เรียก Claude API** จึงยืนยันได้แค่กลไก ไม่ใช่คุณภาพคำตอบ

| ต้องดูตอนรันจริง | ทำไมสำคัญ |
|---|---|
| เวลาคำขอที่ 2 | รอบกู้เพิ่มคำขอเรียงกันจาก 3 → **สูงสุด 5 ต่อจุด** · คลื่นยิงขนาน เวลารวม = สายที่ยาวที่สุด · ประเมิน 100–200 วิ (เดิม 60–120) · เกิน 200 วิบ่อยควรจำกัดรอบกู้เฉพาะจุด `pending` |
| ข้อ 6 ว.2 / ข้อ 22 ว.2 ขึ้นประกาศสุกร 2564 ไหม | ตัวชี้วัดตรงที่สุดว่ารอบกู้ทำงาน |
| มี `source_tier: 'official'` โผล่ไหม | ชี้ว่าชั้น `.go.th`/`.or.th` ได้ใช้จริง |
| โมเดลเสียคำขอกับบล็อกหรือเปล่า | `allowed_domains` ปลดแล้ว กันด้วย prompt อย่างเดียว |

ด่านเวลากันไม่ให้ 504 อยู่แล้ว (รอบกู้ > 60 วิ · ค้นด้วยชื่อ > 55 วิ · อ่านไฟล์ > 45 วิ)
เวลาไม่พอจะข้าม ไม่ใช่ล้ม — แต่แปลว่าถ้าชนเพดาน บางจุดจะไม่ได้รอบกู้

## 6. งานที่ยังค้าง

1. **Token ของ สลค.** (`api.soc.go.th`) — ย้อนดัชนีได้ทั้งคลังแทนที่จะเริ่มที่ มิ.ย. 2566
   ต้องเปิด `www2.soc.go.th` ในเบราว์เซอร์เอง เพราะติด Cloudflare สคริปต์เข้าไม่ได้
   ตารางรองรับแล้วผ่านคอลัมน์ `source = 'soc_api'`
2. **ด่านฉบับที่ถูกแก้/ยกเลิกของกฎหมายที่ถูกอ้างถึง** — ยังเป็นแค่ประโยคใน prompt
   (`anchor-answer.js` · `osh-law-relate.js`) ไม่มีด่านฝั่งโค้ด
   ในดัชนีมีฉบับแก้ไข 2,269 รายการ ทำเป็นด่านเตือนได้ แต่ยังบอกไม่ได้ว่าฉบับไหนแก้ฉบับไหน
   เพราะข้อมูลนั้นอยู่ในเนื้อความ ไม่ใช่ในชื่อเรื่อง
3. **สัญญาอนุญาตของชุดข้อมูล สลค.** ระบุว่า "อื่นๆ" ไม่ชัด — ควรถาม `rsrd@soc.go.th`
   ให้ได้คำตอบเป็นลายลักษณ์อักษรก่อนเก็บถาวรลง DB ที่ลูกค้าใช้
