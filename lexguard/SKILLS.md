# AI Skills — ทะเบียนกฎหมาย SHE

ระบบมี AI Skill 2 ตัว ทำงานเป็น Vercel serverless function เรียกผ่านหน้า "วิเคราะห์ & AI"
ต้องตั้ง env `ANTHROPIC_API_KEY` (และเลือกได้ `ANTHROPIC_MODEL`)

---

## Skill 1 — อ่าน/วิเคราะห์/สรุปกฎหมาย → เข้าทะเบียน
ไฟล์: `api/law-analyze.js` · เรียกจากหน้า Analysis (ปุ่ม "วิเคราะห์ & เตรียมเข้าทะเบียน")

**Input**
```
POST /api/law-analyze   { "source": "<URL หรือ ตัวบทกฎหมาย>", "kind": "auto|text" }
```
- ถ้า source เป็น URL จะดึงเนื้อหาหน้าเว็บมาวิเคราะห์ (ถ้าเป็น PDF ให้วางตัวบทเป็นข้อความ)

**สิ่งที่ Skill สกัดออกมา**
- ระดับกฎหมาย: ชื่อเต็ม, ประเภท, กระทรวง/หน่วยงาน, **วันที่ประกาศ**, **วันที่บังคับใช้** (คำนวณจาก "พ้นกำหนด N วัน" ให้), **เอกสาร/แบบฟอร์มที่ต้องจัดทำ**, หมวด (LA–LG), รหัสที่แนะนำ
- ระดับข้อกำหนด (แตกเป็นข้อย่อยครบทุกมาตรา/ข้อ): เลขมาตรา/ข้อ, เนื้อหา, ผู้รับผิดชอบ, ขอบเขตบังคับใช้, วิธีปฏิบัติ, เอกสาร, ความถี่, เงื่อนไขอื่น

**Output / ผลลัพธ์**
- บันทึกลงตาราง `lg_import_staging` (status=`proposed`)
- โผล่ที่หน้า **"นำเข้า / รออนุมัติ"** → ผู้ใช้กด **"เพิ่มเข้าทะเบียน"** เพื่อย้ายเข้าทะเบียนจริง
  (สร้างกฎหมายใน `lg_laws` พร้อมวันที่ประกาศ/บังคับใช้/เอกสาร และข้อย่อยทั้งหมดใน `lg_requirements`)

## Skill 2 — เฝ้าระวังกฎหมายใหม่จากเว็บไซต์
ไฟล์: `api/law-update.js` · เรียกจากหน้า "อัปเดตกฎหมาย" (ปุ่ม "ตรวจหากฎหมายใหม่")

**Input**
```
POST /api/law-update    {}
```
ดึงหน้า ShawPat (`/th/safety-law`, `/th/other-service/osh-law`) — เพิ่ม/แก้ `SOURCES` ในไฟล์เพื่อเฝ้าเว็บอื่น

**การทำงาน**
1. ดึงข้อความหน้าเว็บ → ให้ Claude สกัด "กฎหมายที่เกี่ยวข้องกับ SHE" (ชื่อ, วันที่ประกาศ, หมวดที่คาด, สรุป 1 บรรทัด)
2. เทียบกับทะเบียน (`lg_laws`) และรายการที่เคยพบ (`lg_law_updates`) เพื่อกรองเฉพาะ **ของใหม่จริง**
3. บันทึกของใหม่ลง `lg_law_updates` (status=`new`) → ขึ้นกระดิ่งแจ้งเตือน + หน้า "อัปเดตกฎหมาย"

**ผลลัพธ์** `{ "scanned": N, "new": M }` — รายการใหม่ให้ผู้ใช้ triage (อ่านแล้ว/เพิ่มแล้ว/ไม่เกี่ยวข้อง)

> ทั้งสอง Skill ทำงานบน Vercel เท่านั้น (ต้อง deploy + ตั้ง ANTHROPIC_API_KEY) — รัน `npm run dev` เฉย ๆ ปุ่มจะเรียก API ไม่ได้
