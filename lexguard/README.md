# LexGuard — ระบบทะเบียนกฎหมาย SHE & ติดตามความสอดคล้อง

ระบบเว็บแอปสำหรับ จป. วิชาชีพ ของ **บริษัท จัสเทล เน็ทเวิร์ค** ใช้จัดการทะเบียนกฎหมาย
ความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน (SHE) พร้อมติดตามความสอดคล้อง
วิเคราะห์/สรุปด้วย AI และตารางการสื่อสารองค์กร (ISD-86)

สร้างด้วย **React + Vite + Supabase (PostgreSQL)**

## ฟีเจอร์
- **ภาพรวม (Dashboard)** — สถิติ, วงแหวน % ความสอดคล้อง, แท่งรายหมวด, รายการ NC
- **ทะเบียนกฎหมาย** — 131 ฉบับ 7 หมวด ค้นหา/กรองได้ คลิกดูรายละเอียด
- **ติดตามความสอดคล้อง** — แยกรายหมวด/ข้อกำหนด แก้ไขสถานะ C/NC แล้ว**บันทึกลงฐานข้อมูลทันที**
- **การสื่อสาร (ISD-86)** — ตารางการสื่อสารภายใน/ภายนอกองค์กร
- **วิเคราะห์ & สรุป AI** — บทสรุปผู้บริหาร ข้อค้นพบ และข้อเสนอแนะ
- **การแจ้งเตือน** — กระดิ่งแจ้งรายการ NC และกฎหมายที่ใกล้ครบกำหนดทบทวน (≤ 60 วัน)
- **ส่งออก PDF** — รายงานสำหรับการตรวจประเมิน (ปุ่ม "ส่งออก PDF" → พิมพ์/บันทึกเป็น PDF)
- **แถบเมนูย่อ/ขยายได้ (slide bar)** เข้าถึงทุกหน้ารวมถึงหน้าวิเคราะห์กฎหมาย

## ข้อมูล (ฝังจริงแล้วใน Supabase)
- 7 หมวด (LA–LG) · 131 ฉบับ · 164 ข้อกำหนด · 2 รายการยังไม่สอดคล้อง (LA-031, LA-032) · 26 รายการสื่อสาร
- โครงการ Supabase: `lexguard / legal-registry 2` (region: Singapore ap-southeast-1)
- ตารางใช้ prefix `lg_` แยกจากตารางเดิมในโครงการ

## การติดตั้งและรันในเครื่อง
```bash
npm install
npm run dev        # เปิด http://localhost:5173
```
ค่าเชื่อมต่อ Supabase อยู่ในไฟล์ `.env` (URL + publishable key — เป็น key สาธารณะ ปลอดภัยที่จะฝังใน client)

## Deploy ขึ้น Vercel
1. push โฟลเดอร์นี้ขึ้น GitHub
2. ที่ vercel.com → New Project → Import repo
3. เพิ่ม Environment Variables 2 ตัว (จากไฟล์ `.env`):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Framework = Vite, Build = `npm run build`, Output = `dist` → Deploy

หรือใช้ CLI:
```bash
npm i -g vercel
vercel        # ตอบ prompt และตั้ง env vars
vercel --prod
```

## โครงสร้างโปรเจกต์
```
lexguard/
├─ src/
│  ├─ App.jsx                 # แอปหลัก + 5 หน้า + sidebar + แจ้งเตือน + PDF
│  ├─ index.css               # ดีไซน์ระบบทั้งหมด (รวม @media print)
│  ├─ lib/supabase.js         # client + data access (อ่าน/เขียน)
│  └─ components/
│     ├─ icons.jsx            # ไอคอน SVG
│     ├─ LawDrawer.jsx        # แผงรายละเอียดกฎหมาย + แก้ไขสถานะ
│     └─ report.jsx           # ตัวสร้างรายงาน PDF สำหรับตรวจประเมิน
├─ supabase/schema.sql        # โครงสร้างฐานข้อมูล
├─ source-data/               # ไฟล์ Excel ต้นฉบับขององค์กร
├─ .env                       # ค่าเชื่อมต่อ Supabase
└─ package.json
```

## หมายเหตุด้านความปลอดภัย
ปัจจุบันใช้ RLS แบบเปิด (อ่าน/เขียนได้ด้วย anon key) เพื่อให้แก้ไข/บันทึกได้ทันทีสำหรับใช้งานภายใน
**ก่อนเปิดใช้งานจริงในวงกว้าง** ควรเพิ่ม Supabase Auth (ล็อกอิน) และจำกัด policy ให้เขียนได้เฉพาะผู้มีสิทธิ์
